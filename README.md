🚀 Project Overview
This project focuses on creating a comprehensive and interactive UK Employment Dashboard using Tableau Public. The primary objective was to analyse employment data across different industries and geographical locations within the UK, demonstrating skills in data aggregation, trend calculation, and geographic visualisation.

The project highlights key employment trends, identifying top-performing sectors and cities with the highest employment growth.

📊 Key Visualisations and Analysis
The dashboard integrates multiple views to provide a multi-faceted analysis of the UK job market:

UK Employment Dashboard
The central interactive view allowing users to filter by time, city, or industry.
Visualises employment figures across different UK cities, often using a map to show geographic concentration and comparative bar charts to rank cities by volume.

Average Percentage Change in Employment by City
Calculates and displays the Average Percentage Change in employment over a specific time period for various cities. This is crucial for identifying areas experiencing the fastest (or slowest) job market growth.

Top 10 Sub-Industries
A more granular analysis that identifies and ranks the top 10 sub-industries (more detailed categories within a major industry) by employment count.
